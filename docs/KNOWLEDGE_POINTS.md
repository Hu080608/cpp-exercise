## 第 1 章 · 程序和 C++ 基础

### 1.1 计算机与程序的基本概念

- **来源**：`第01章.pptx` · slide 7–13
- **课程章节**：1.1
- **题库**：10 题（单选、多选、判断、填空、代码阅读、编程；难度 入门、简单、中等）

计算机由硬件与软件组成；程序是数据与处理规则的描述；冯·诺依曼体系包含存储、运算、控制、输入、输出五个单元，核心思想是存储程序。

**核心知识点**

- 硬件是物理构成，软件是程序及相关文档；功能主要由软件提供。
- 冯·诺依曼计算机的逻辑五单元：存储单元、运算单元、控制单元、输入单元、输出单元。
- 存储程序式计算机：程序先装入存储单元，再由控制单元逐条取指执行。
- 程序 = 算法 + 数据结构；算法描述处理步骤，数据结构描述数据。
- 系统软件、支撑软件、应用软件的分层与用途。
- cache 利用程序访问的局部性缓解高速设备与低速设备速度不匹配。

**易错提醒**

- 把硬件性能与软件功能混为一谈。
- 认为程序就是指令本身而忽略数据与文档。

### 1.2 数制、编码与整数机器表示

- **来源**：`第01章.pptx` · slide 14–23
- **课程章节**：1.1
- **题库**：13 题（单选、多选、判断、填空、代码阅读；难度 入门、简单、中等、困难）

计算机内部使用二进制；常用八进制、十进制、十六进制；整数可用原码、反码、补码表示，现代整数运算采用补码。

**核心知识点**

- 1 字节 = 8 bit；1 KB = 1024 B，KB→MB→GB→TB 均以 1024 进位。
- 十进制整数转二进制：除 2 取余、逆序排列；十进制小数转二进制：乘 2 取整、顺序排列。
- 二、八、十六进制可按 3 位、4 位一组直接互转。
- 原码 = 符号位 + 绝对值；反码为负数除符号位外按位取反；补码为反码加 1。
- n 位补码范围：-2^(n-1) ~ 2^(n-1)-1；0 只有一种补码表示。
- 补码把减法转成加法，最高位进位舍去。

**易错提醒**

- 把负数的补码误当成“绝对值加符号位”。
- 混淆十进制小数转换的方向。

### 1.3 程序设计范式、步骤与语言

- **来源**：`第01章.pptx` · slide 24–32
- **课程章节**：1.2
- **题库**：11 题（单选、多选、判断、填空、代码阅读、编程；难度 入门、简单、中等、困难）

程序设计范式包括过程式、对象式、函数式、逻辑式；程序设计步骤为需求分析、系统设计、实现、测试与调试、运行维护；高级语言通过编译、解释或混合方式翻译。

**核心知识点**

- 过程式以功能为中心；对象式以数据/对象为中心；函数式以函数应用为中心；逻辑式以事实和推理规则为中心。
- 程序设计步骤：需求分析（做什么）→ 系统设计（如何做）→ 实现 → 测试与调试 → 运行维护。
- 测试只能发现错误，不能证明程序没有错误；调试是定位并改正错误。
- 低级语言：机器语言、汇编语言；高级语言可移植性更好、开发效率更高。
- 编译方式产生目标代码；解释方式逐条翻译并执行且不产生目标代码；混合方式先编译成中间语言再解释。
- C++ 是编译型、静态类型、支持过程式与面向对象范式的混合式高级语言。

**易错提醒**

- 把“编译”和“解释”产生的产物混为一谈。
- 把测试当作正确性证明。

### 1.4 C++ 词法：字符集、标识符、关键词与注释

- **来源**：`第01章.pptx` · slide 33–39
- **课程章节**：1.3
- **题库**：11 题（单选、多选、判断、填空、代码阅读、编程；难度 入门、简单、中等）

C++ 单词包括标识符、关键词、字面常量、操作符和标点符号；标识符由字母、数字、下划线组成且首字符不能是数字；注释不参与执行。

**核心知识点**

- 标识符首字符不能为数字；区分大小写；关键词不能作自定义标识符。
- 建议避免以两个下划线开头，或一个下划线后跟大写字母开头的全局标识符。
- 整数、实数、字符、字符串字面常量的书写形式不同。
- 多行注释 /* ... */ 不能嵌套；单行注释 // 延续到本行结束。
- 空白符用于分隔单词；续行符为反斜杠后紧跟回车。
- C++ 程序从 main 开始执行，main 返回 0 通常表示正常结束。

**易错提醒**

- 把 #include 当成普通语句并在末尾加分号。
- 把字符串 "a" 与字符 'a' 混用。

## 第 2 章 · 数据与表达式

### 2.1 数据类型与基本类型

- **来源**：`第02章.pptx` · slide 3–10
- **课程章节**：2.1–2.2
- **题库**：12 题（单选、多选、判断、填空、代码阅读；难度 入门、简单、中等）

数据类型由值集与操作集构成；C++ 基本类型包括整数、实数、字符、逻辑和 void；整型采用补码表示，不同类型占用空间与范围不同。

**核心知识点**

- 简单类型的数据不可再分解；复合类型由其他类型按规则组织。
- 整型：short、int、long、long long，以及对应的 unsigned 无符号版本。
- 实数型：float、double、long double；实数可能无法精确表示（如 0.1）。
- char 存储字符编码；bool 的值为 true/false，通常占 1 字节。
- void 表示空值类型，可用于无返回值函数与 void* 通用指针。
- typedef 为已有类型起别名，不创造新类型。

**易错提醒**

- 记错各类型典型字节数或不理解范围。
- 认为浮点数总能精确表示十进制小数。

### 2.2 常量、变量与初始化

- **来源**：`第02章.pptx` · slide 11–17
- **课程章节**：2.3
- **题库**：8 题（单选、多选、判断、填空、代码阅读；难度 入门、简单、中等）

常量在运行中不可改变，可用字面常量或 const/#define 符号常量表示；变量由类型、名字、值、存储空间和地址等属性构成。

**核心知识点**

- 整数字面量默认 int；后缀 L、U、UL 可改变类型。
- 实数字面量默认 double；后缀 F 表示 float，L 表示 long double。
- 字符常量用单引号；字符串字面量用双引号，并以 '\0' 结束。
- const 定义符号常量；#define 是预处理文本替换。
- 变量定义可写作 int a=0; 或 int a(0);，同类型变量可用逗号一起定义。
- C++ 是静态类型语言，变量使用前必须有确定类型。

**易错提醒**

- 把 int a=b=1; 当成合法定义。
- 忽视字符串结尾的 '\0' 占一个字符位置。

### 2.3 输入输出与格式化

- **来源**：`第02章.pptx` · slide 18、37–39
- **课程章节**：2.3 / 2.5
- **题库**：16 题（单选、多选、判断、填空、代码阅读、编程；难度 入门、简单、中等）

cin 与 >> 读取输入，cout 与 << 输出；输入默认以空白符分隔；iomanip 控制宽度、填充、精度和对齐。

**核心知识点**

- cin >> 读取时以空格、制表符或回车分隔数据，格式应与变量类型相符。
- cout << 可连续输出；endl 输出换行并刷新流。
- setw(n) 只影响下一次输出；setfill(c) 设置填充字符并保持。
- fixed + setprecision(n) 表示小数点后 n 位；scientific 使用科学计数法。
- hex、dec、oct 改变整数的输出进制，不改变变量存储值。
- 使用格式控制符需包含 <iomanip>。

**易错提醒**

- 认为 setw 会持续影响后续所有输出。
- 混淆有效位数 setprecision 与定点小数位数。

### 2.4 算术、关系与逻辑运算

- **来源**：`第02章.pptx` · slide 19–29
- **课程章节**：2.4
- **题库**：27 题（单选、多选、判断、填空、代码阅读、编程；难度 入门、简单、中等、困难）

算术运算、自增自减、关系运算和逻辑运算各有结果类型与求值规则；&& 与 || 支持短路求值。

**核心知识点**

- 两个整数相除执行整除，结果向零截断；% 求余数。
- ++x 先加后用；x++ 先用后加；操作数必须是可修改的变量。
- 关系运算结果为 bool；逻辑运算把 0 视为 false、非 0 视为 true。
- && 与 || 短路求值：前一操作数能决定结果时不计算后一操作数。
- 常见错误：10 < age < 30 不等价于 10 < age && age < 30。
- 赋值 = 与相等 == 不能混用。

**易错提醒**

- 在复杂表达式中对同一变量多次使用带副作用的 ++/--。
- 把逻辑与 & 当成逻辑与 &&。

### 2.5 类型转换、表达式求值与位运算

- **来源**：`第02章.pptx` · slide 21–36
- **课程章节**：2.4–2.5
- **题库**：24 题（单选、多选、判断、填空、代码阅读、编程；难度 入门、简单、中等、困难）

混合算术运算按常规算术转换规则提升类型；表达式按优先级和结合性分组；位运算直接处理二进制位。

**核心知识点**

- 隐式转换把精度低的类型向精度高的类型转换；有符号与无符号混合时可能产生意外结果。
- 显式转换写法：类型名(操作数) 或 (类型名)操作数。
- 整型提升把 bool、char、short 等提升为 int（或 unsigned int）。
- 优先级：算术 > 关系 > 逻辑；赋值右结合；条件运算符右结合。
- 位运算：~ 按位取反、& 按位与、| 按位或、^ 按位异或、<< 左移、>> 右移。
- C++ 一般未规定不相邻操作符的求值次序；含副作用时结果可能不确定。

**易错提醒**

- 对有符号数与无符号数直接比较大小。
- 把逻辑运算和位运算混为一谈。

## 第 3 章 · 流程控制

### 3.1 语句、顺序结构与表达式语句

- **来源**：`第03章.pptx` · slide 10–18

流程控制决定语句何时执行；C++ 语句分为顺序、选择、循环、无条件转移和声明；复合语句用花括号把多条语句组合为一个整体。

**核心知识点**

- 表达式语句格式为“表达式;”；单独的分号是空语句。
- 复合语句（语句块）是一个整体，可作为 if、循环等的子语句。
- if/else 默认只控制紧随其后的一条子语句；多条语句必须用花括号。
- 流程图是算法的语言无关表示。
- 顺序执行时语句按书写次序执行。

**易错提醒**

- 缩进变化不会改变 else 的配对对象。
- if 后漏写花括号导致多条语句中只有第一条受控。

### 3.2 选择结构：if、else 与 switch

- **来源**：`第03章.pptx` · slide 19–30
- **课程章节**：3.3
- **题库**：26 题（单选、多选、判断、填空、代码阅读、编程；难度 入门、简单、中等、困难）

if 根据条件选择执行分支；else 与最近的未配对 if 结合；switch 根据整数/枚举表达式选择 case 入口。

**核心知识点**

- if 条件可转换为 bool：0 为 false，非 0 为 true。
- else 默认与最近的、尚未配对的 if 结合（悬空 else）。
- else-if 链适合互斥区间判断，命中一个分支后其余分支不再判断。
- switch 的 case 标签必须是常量表达式；进入某个 case 后会继续向下执行，直到 break 或 switch 结束。
- 多个 case 可共用一个分支；default 处理未匹配情况。
- 漏写 break 会造成贯穿（fall-through）。

**易错提醒**

- 误以为 switch 会在匹配 case 后自动停止。
- 把 if (x=1) 当作比较。

### 3.3 循环结构：while、do-while、for 与嵌套

- **来源**：`第03章.pptx` · slide 31–64
- **课程章节**：3.4
- **题库**：56 题（单选、多选、判断、填空、代码阅读、编程；难度 入门、简单、中等、困难）

循环由初始化、条件、循环体、更新四部分组成；while 先判断，do-while 至少执行一次，for 把控制部分集中书写。

**核心知识点**

- while 条件为 false 时循环体一次也不执行；do-while 先执行一次再判断，末尾必须有分号。
- for 的执行顺序：初始化一次 → 条件判断 → 循环体 → 更新 → 再判断。
- for 的表达式1可定义变量，其作用域只在这条 for 语句内。
- 循环体必须让状态向退出条件推进，或通过 break 等方式结束。
- 嵌套循环中，内层循环会在外层每一轮完整执行。
- 常见算法：累加、累乘、素数判断、Fibonacci、穷举、牛顿迭代。

**易错提醒**

- 忘记更新循环变量造成死循环。
- do-while 末尾漏分号或初值设置错误。

### 3.4 转移语句与程序设计风格

- **来源**：`第03章.pptx` · slide 65–83
- **课程章节**：3.5–3.6
- **题库**：10 题（单选、多选、判断、填空、代码阅读；难度 入门、简单、中等、困难）

goto、break、continue、return 改变执行流程；结构化程序设计强调顺序、选择、循环和清楚的单入口/单出口。

**核心知识点**

- break 结束最近一层 switch 或循环；continue 跳过本轮剩余语句。
- continue 在 while 中跳到条件判断，在 for 中先执行表达式3。
- goto 只能在同一函数内跳转，不能跨函数；不能绕过变量初始化。
- return 立即结束当前函数并返回调用处。
- 结构化程序通常由顺序、选择、循环三种基本结构组合而成。
- 应优先使用能清楚表达意图的结构，避免不必要的 goto。

**易错提醒**

- 以为 break 能一次退出多层嵌套循环。
- 在 while 中用 continue 时忘记推进循环变量。

## 第 4 章 · 函数与过程抽象

### 4.1 过程抽象、函数定义与调用

- **来源**：`第04章-01.pptx` · slide 3–16
- **课程章节**：4.1–4.2
- **题库**：10 题（单选、多选、判断、填空、代码阅读；难度 入门、简单、中等）

函数是 C++ 实现子程序的语言成分；函数支持功能分解、复用、过程抽象与信息隐藏；参数负责传入数据，return 负责返回结果。

**核心知识点**

- 函数定义格式：返回值类型 函数名(形参表) 函数体。
- main 是程序入口，有且只有一个；普通函数只有被调用才执行。
- 函数声明只给出函数头信息，使调用点能检查参数个数和类型；函数体不能嵌套定义。
- return 结束函数；返回值可与返回值类型隐式转换；void 函数可无 return。
- 值传递把实参值复制给形参，形参改变不影响实参。
- C++ 标准未规定多个实参的计算次序。

**易错提醒**

- 把函数声明与定义混淆。
- 认为值传递能修改调用者的实参。

### 4.2 局部变量、全局变量与作用域

- **来源**：`第04章-01.pptx` · slide 17–21；第04章-3 slide 36
- **课程章节**：4.3
- **题库**：8 题（单选、多选、判断、填空、代码阅读；难度 入门、简单、中等）

局部变量在复合语句或函数内定义，形参也是局部变量；全局变量在函数外定义；局部 static 对象的值可跨调用保留。

**核心知识点**

- 局部变量的作用域限于定义它的块，块外不可访问。
- 全局变量可被多个函数访问，但会破坏函数的引用透明性并引入副作用。
- 函数副作用：函数改变了非局部量的值。
- extern 声明全局变量，不分配新的存储空间；定义只能有一个。
- 局部 static 对象具有静态存储期，但名字仍只在所在作用域可见。
- 应尽量避免不必要的全局变量。

**易错提醒**

- 把同名不同作用域的变量当成同一个变量。
- 认为 static 局部变量的值每次调用都会重置。

### 4.3 多模块结构与标准库函数

- **来源**：`第04章-01.pptx` · slide 22–28
- **课程章节**：4.4
- **题库**：7 题（单选、多选、判断、填空、代码阅读；难度 入门、简单、中等）

C++ 程序可按逻辑单位分为多个源文件模块，接口放头文件、实现放 .cpp；标准库功能按头文件组织。

**核心知识点**

- 模块接口放 .h 文件，实现放 .cpp 文件；各模块单独编译，再由链接器合并。
- #include <文件名> 优先在系统目录查找；#include "文件名" 优先在源文件目录查找。
- C++ 标准库头文件使用 c 前缀（如 <cmath>、<cstdlib>、<cctype>、<cstring>）。
- cmath 常用函数：sqrt、fabs、pow、ceil、floor、sin、cos、log。
- cstdlib 常用函数：abs、labs、rand、srand、exit、abort。
- cctype 字符判断/转换：isdigit、isalpha、isalnum、isupper、islower、tolower、toupper。

**易错提醒**

- 忘记包含对应头文件。
- 混用 <math.h> 与 <cmath> 的命名空间差异。

### 4.4 递归函数

- **来源**：`第04章-02.pptx` · slide 3–31
- **课程章节**：4.5
- **题库**：21 题（单选、多选、判断、填空、代码阅读、编程；难度 入门、简单、中等、困难）

递归函数直接或间接调用自身；递归必须包含结束条件与递归条件，并让实参向结束条件收敛；每次调用产生独立局部变量实例。

**核心知识点**

- 递归适合分而治之且子问题与原问题同性质的问题。
- 必须有结束条件（基底）和递归条件；缺少结束条件会无限递归。
- 递归调用使用栈空间，每次调用有独立的形参和局部变量。
- 递归可能重复计算（如朴素 Fibonacci），效率可能低于循环。
- 递归可以表达阶乘、Fibonacci、汉诺塔等自然递归的问题。
- 递归深度受栈空间限制，函数调用本身有开销。

**易错提醒**

- 只写递归条件而漏掉结束条件。
- 递归实参没有向结束条件靠近。

### 4.5 宏、内联函数、默认参数与命名空间

- **来源**：`第04章-3.pptx` · slide 14–36
- **课程章节**：4.6
- **题库**：10 题（单选、多选、判断、填空、代码阅读、编程；难度 入门、简单、中等、困难）

宏是预处理文本替换；inline 函数保留类型检查与参数求值语义；默认参数只能从右端连续省略；命名空间用于避免名字冲突。

**核心知识点**

- 带参宏没有函数调用语义，参数和整体通常都要加括号。
- 宏可能造成参数重复求值（如 MAX(++x, y)）。
- inline 提示编译器展开，但不保证展开；实参每次调用只求值一次。
- 默认参数必须连续靠右；同一作用域内默认值只指定一次。
- namespace 用 :: 限定名字；using namespace 引入整个命名空间。
- 匿名命名空间中的名字具有内部链接；using 声明只引入指定名字。

**易错提醒**

- 以为 inline 一定展开。
- 在宏参数中传入带副作用的表达式。

### 4.6 函数重载、函数指针、Lambda、范围 for 与 auto

- **来源**：`第04章 - 3-2.pptx` · slide 3–50
- **课程章节**：4.6
- **题库**：14 题（单选、多选、判断、填空、代码阅读、编程；难度 入门、简单、中等、困难）

函数重载按参数类型/个数区分；函数指针可保存函数地址并实现回调；Lambda 可捕获外层变量；范围 for 遍历数组；auto 由初始化表达式推导类型。

**核心知识点**

- 重载要求参数类型或个数不同；仅返回值不同不能重载。
- 重载决议：精确匹配优于提升，提升优于普通转换；没有唯一最佳候选则歧义。
- 函数指针声明 double (*fp)(int)；函数名可自动转换为函数指针。
- 无捕获 Lambda 可转换为函数指针；带捕获 Lambda 不能。
- 范围 for 中 int n 是副本，int& n 可修改元素。
- auto 必须有初始化式，类型在编译期推导，不是运行时动态类型。

**易错提醒**

- 仅改变返回值类型来重载。
- 把带捕获的 Lambda 赋给普通函数指针。

### 4.7 动态内存：new/delete 与 malloc/free

- **来源**：`第04章-3.pptx` · slide 37–45
- **课程章节**：4.6
- **题库**：8 题（单选、多选、判断、填空、代码阅读、编程；难度 入门、简单、中等、困难）

new 创建动态对象并返回指针；delete 释放单个对象，delete[] 释放数组；malloc/calloc 与 free 是 C 风格动态内存函数。

**核心知识点**

- new int 不初始化；new int() 初始化为 0；new int[n]{} 将元素置零。
- new[] 必须配 delete[]；new 必须配 delete。
- malloc 返回 void*，C++ 中需转换后使用；malloc 不初始化内容。
- calloc(n, size) 将分配的内存清零。
- 动态对象离开作用域不会自动释放；未释放造成内存泄漏。
- 释放后继续访问形成悬空指针（悬浮指针）。

**易错提醒**

- new[] 后用 delete 而非 delete[]。
- delete 局部变量的地址。

### 5.1 枚举类型

- **来源**：`第05章 - 1.pptx` · slide 4–16
- **课程章节**：5.1
- **题库**：9 题（单选、多选、判断、填空、代码阅读、编程；难度 入门、简单、中等）

枚举类型由用户列出一组整型符号常量作为值集；枚举值默认从 0 递增，也可显式指定。

**核心知识点**

- enum Day {SUN,MON,TUE,WED,THU,FRI,SAT}; 中 SUN 为 0，依次递增。
- 枚举变量只能取本枚举值集中的值；不能直接把整数赋给枚举变量。
- 枚举值可参与算术、关系和逻辑运算，运算结果不再是枚举类型。
- 枚举变量不能直接输入，但可以直接输出其对应的整数。
- 可用 switch 把整数转换为相应的枚举值。
- 枚举提高可读性，但输入输出较麻烦。

**易错提醒**

- 把不同枚举类型的枚举值互相赋值。
- 把 d+1 直接赋给枚举变量而不做显式转换。

### 5.2 一维数组

- **来源**：`第05章 - 1.pptx` · slide 17–55
- **课程章节**：5.2
- **题库**：27 题（单选、多选、判断、填空、代码阅读、编程；难度 入门、简单、中等、困难）

一维数组由固定多个同类型元素按线性次序构成；元素在内存中连续存放，下标从 0 开始。

**核心知识点**

- 数组元素个数必须是整型常量表达式；元素类型不能是 void。
- 初始化值不足时其余元素补 0；全部初始化时可省略元素个数。
- 数组不能整体赋值，需逐元素复制。
- C++ 不检查数组下标越界，越界访问是未定义行为。
- 一维数组作为函数参数时传递首地址，需要另行提供元素个数。
- 数组名在多数表达式中转换为指向首元素的指针。

**易错提醒**

- 下标从 1 开始或循环条件写成 i<=n。
- 试图用 a=b 整体复制数组。

### 5.3 字符串与字符数组

- **来源**：`第05章 - 1.pptx` · slide 56–89
- **课程章节**：5.2
- **题库**：32 题（单选、多选、判断、填空、代码阅读、编程；难度 入门、简单、中等、困难）

C++ 以字符数组存储 C 风格字符串，字符串以 '\0' 结束；字符数组长度应比字符串最大长度多 1。

**核心知识点**

- 字符串 "lie" 需要 4 个 char：'l'、'i'、'e'、'\0'。
- 字符串字面量可直接初始化字符数组，编译器自动补 '\0'。
- cin >> 字符数组会在空白处停止；cin.getline 可读含空格的整行。
- 字符串处理函数依赖 '\0' 判断结束。
- strlen 返回有效字符数，不包含 '\0'；strcmp 按字典序比较。
- 字符串整体赋值/比较不能直接用 = 或 ==，应使用 strcpy/strcmp 等库函数。

**易错提醒**

- 字符数组容量刚好等于字符串长度，导致无处存放 '\0'。
- 用 == 比较两个 C 风格字符串的内容。

### 5.4 二维数组

- **来源**：`第05章 - 1.pptx` · slide 82–109
- **课程章节**：5.2
- **题库**：16 题（单选、多选、判断、填空、代码阅读、编程；难度 入门、简单、中等、困难）

二维数组表示行列结构，元素按行优先在内存中连续存放；二维数组作形参时列数必须写明。

**核心知识点**

- 定义 int a[行数][列数]；两个下标都从 0 开始。
- 初始化可按行分组，也可按行优先顺序平铺。
- a[i] 表示第 i 行这个一维数组。
- 二维数组参数可写 int x[][5]，列数必须为常量；行数会被忽略，通常另传。
- a[i][j] 的地址 = 首地址 + (i × 列数 + j) × 元素大小。
- 按列访问在行优先存储下缓存局部性较差。

**易错提醒**

- 函数形参漏写列数。
- 把二维数组名直接赋给 int**。

### 5.5 结构体类型

- **来源**：`第05章 - 1.pptx` · slide 100–124
- **课程章节**：5.3
- **题库**：15 题（单选、多选、判断、填空、代码阅读、编程；难度 入门、简单、中等、困难）

结构体把固定多个、类型可以不同的成员组织成一个复合数据；相同结构体类型变量可以整体赋值。

**核心知识点**

- struct 定义新类型；成员类型不能是 void 或本结构自身。
- 用 . 访问成员；结构体变量可整体赋值。
- 结构体变量内存连续，成员按定义次序存放，可能存在对齐填充。
- 结构体作函数参数默认值传递，修改形参不影响实参。
- 结构体数组每个元素是一个结构体，常用于名表。
- 结构体可作函数返回值。

**易错提醒**

- 用不同结构体类型变量互相赋值。
- 以为 sizeof(struct) 一定等于成员大小之和。

### 5.6 联合体类型

- **来源**：`第05章 - 1.pptx` · slide 125–138
- **课程章节**：5.4
- **题库**：5 题（单选、多选、判断、填空、代码阅读；难度 入门、简单、中等）

联合体成员共用同一块存储空间，大小取最大成员所需空间；同一时刻只应使用一个有效成员。

**核心知识点**

- union 的成员互斥，不能同时有效使用。
- 联合体大小通常等于最大成员大小（考虑对齐）。
- 需额外标记当前有效成员的类型。
- 可用 struct 把类型标记和联合体组合起来。
- 联合体可包含数组等类型。

**易错提醒**

- 写入一个成员后读取另一个成员。
- 把联合体当成能同时保存所有成员的容器。

### 5.7 指针、指针运算与函数指针

- **来源**：`第05章 - 2.pptx` · slide 3–119
- **课程章节**：5.5
- **题库**：13 题（单选、多选、判断、填空、代码阅读、编程；难度 入门、简单、中等、困难）

指针保存内存地址；& 取地址、* 间接访问；指针加减按所指类型大小移动；函数指针保存函数地址。

**核心知识点**

- 指针变量本身也占内存，其值是另一个对象的地址。
- 同类型指针才能直接赋值；void* 可保存任意对象地址，但访问前需转换。
- 指针加减整数按元素大小缩放；同类型指针相减得到相差元素个数。
- 结构指针用 p->member 或 (*p).member 访问成员。
- 通过指针参数可修改调用者数据；数组参数本质上传递首地址。
- const int* 指向常量；int* const 是指针常量；函数指针声明需把 * 与变量名括起来。

**易错提醒**

- 使用未初始化指针。
- 混淆指向常量的指针与指针常量。

### 5.8 动态内存与链表

- **来源**：`第05章 - 2.pptx` · slide 44–103
- **课程章节**：5.5
- **题库**：11 题（单选、多选、判断、填空、代码阅读、编程；难度 入门、简单、中等、困难）

动态变量在堆区创建并通过指针访问；链表由动态结点和指针链接而成，适合频繁插入删除。

**核心知识点**

- new/malloc 创建的动态对象生存期由程序员管理。
- 动态数组用 new[] 创建、delete[] 释放；malloc 创建的用 free。
- 指针丢失会导致内存泄漏；释放后继续访问产生悬空指针。
- 链表结点包含数据域和 next 指针域；头指针标识链表。
- 头插法把新结点放到表头；尾插法需找到尾结点。
- 链表访问元素效率低，但插入删除效率高；数组则相反。

**易错提醒**

- delete[] 前移动了动态数组指针。
- 链表删除结点前丢失后继地址。

### 5.9 引用类型

- **来源**：`第05章 - 2.pptx` · slide 120–141
- **课程章节**：5.6
- **题库**：10 题（单选、多选、判断、填空、代码阅读、编程；难度 入门、简单、中等、困难）

引用是已有对象的别名；定义时必须初始化，且之后不能改为引用其他对象；引用参数可修改实参并避免复制。

**核心知识点**

- int& r = x; 后 r 与 x 访问同一对象。
- 引用必须初始化，类型应与被引用对象一致。
- 引用初始化后不能重新绑定到其他变量。
- 引用参数调用时直接传变量名，可修改实参。
- const 引用只读且可接收临时对象，适合大对象传参。
- 不能返回局部变量的引用；返回引用可让调用者访问原对象。

**易错提醒**

- 把引用当成独立变量。
- 返回局部变量的引用或指针。
