## 二、参考站没有、本站超越的功能

| 能力 | 本站实现 | 价值 |
|---|---|---|
| 真实 C++ 编译运行 | 内置 C++ 沙箱，可编辑、用自定义 stdin 运行，显示 GCC 编译错误、运行输出与退出状态 | 从“看代码”升级为“写代码并验证” |
| 编程题自动评测 | 17 道编程题，含初始代码、样例/隐藏测试、逐测试用例通过状态；“提交评测”真实编译运行 | 支撑完整编程练习闭环 |
| 编程题可重试 | 失败会记录一次错误但保持可编辑，修改后可继续提交；通过即记录正确 | 符合编程学习“调试—修改—再试”的真实过程 |
| 六种题型 | 在参考站四类题基础上增加代码阅读、编程题 | 覆盖读代码、写代码能力 |
| 四档难度 | 入门 / 简单 / 中等 / 困难，界面与筛选器均可筛选 | 比参考站三档更细，初学者和进阶者都有入口 |
| 多条件筛选 | 章节 × 知识点 × 题型 × 难度 × 状态 × 关键词 | 可以精确构造“第 3 章 + 循环 + 困难 + 未做”的训练集 |
| 收藏夹 | 任意题目可收藏，按收藏筛选、单题重练 | 建立个人重点题单 |
| 知识点来源 | 每道题解析显示 PPT 文件名 + 章节 + slide；知识点地图记录 29 个知识点的来源 | 可抽查、可审计，避免超纲 |
| 知识点 × 题库联动 | 知识点详情页显示关联题目数量、正确率、一键专练 | 发现薄弱点到立即练习的路径更短 |
| 答题地图 | 抽屉式题号地图，按作答状态着色，可跳题 | 长练习中快速定位 |
| 每日目标与打卡 | 可调整 5/10/20/30/50/100 题每日目标，统计连续学习天数 | 建立学习节奏 |
| 学习活动曲线 | 最近 7 天答题量柱状图、每天正确数/学习时长 | 让进度可视化 |
| 数据导出格式 | 导出完整学习状态（记录/收藏/活动/设置），可跨设备恢复 | 比单纯记录备份更完整 |
| 纯静态部署 | 无构建、无自建后端；GitHub Pages 直接托管；题库 JSON 与代码分离 | 部署简单、维护成本低 |
| PWA 离线壳 | Service Worker 缓存页面、知识点和题库；编译需联网 | 断网也能看知识点和刷不需要编译的题 |
| 题库校验脚本 | `scripts/build_questionbank.py` 自动校验 24 个题型×难度组合、29 个知识点覆盖 | 后续增题不会破坏覆盖矩阵 |
| 编程题回归测试 | `scripts/test_programming.py` 用本机 g++ 编译运行全部标准解 | 防止标准解与测试用例漂移 |

## 三、验收对照

- 参考站 23 项功能：**全部实现**。
- 题型 × 难度：**6 × 4 = 24 个组合全部有题**。
- 知识点：**29 个，全部有题**，逐项标注 PPT 来源。
- 沙箱：**可编译运行正确代码、错误代码可读报错**；编译器由 Wandbox 公共 API 提供，无需自建后端。
- 响应式：桌面 1200px 三栏/双栏布局，移动端底部导航与单列卡片；题目地图在移动端为抽屉。
