# 功能清单

C++ Lab 是一个面向「程序设计」课程复习的纯静态练习网站，覆盖课程 PPT 第 1–5 章。

## 题库与练习

- 447 道题：单选、多选、判断、填空、代码阅读、编程题。
- 四档难度：入门、简单、中等、困难，可按题型和难度筛选。
- 29 个知识点，逐题标注 PPT 文件、章节与 slide 来源。
- 按章节、知识点、题型、难度、作答状态和关键词组合筛选。
- 即时判分与解析；错题自动收录，连续答对 2 次移出。
- 收藏夹、题目地图、键盘快捷键、本地进度自动保存。

## 编程训练

- 167 道编程题，含初始代码、标准解、样例/隐藏测试与知识点来源。
- 编程训练场支持按难度、状态和训练路线筛选。
- 提交后逐测试用例显示通过状态。
- 提交或查看答案后，代码编辑器、运行和重新评测仍然可用。
- 参考解自动格式化展示，并支持一键复制。

## C++ 沙箱

- 页面内编辑、编译、运行 C++17 程序。
- 支持自定义 stdin、标准输出、编译错误与运行错误提示。
- Judge0 CE 主通道 + Wandbox 备用通道，服务繁忙时自动切换并重试。
- 代码编辑支持 Tab 插入 4 个空格、Shift+Tab 取消缩进。

## 学习数据

- 首页学习概览、每日目标、连续学习天数。
- 各章、题型、难度正确率与薄弱知识点统计。
- 最近 7 天答题量图表。
- 学习记录导出/导入、本地保存、会话恢复。
- 深色/浅色/跟随系统主题，移动端响应式布局。

## 部署

- 无构建工具、无框架依赖，直接托管在 GitHub Pages。
- PWA 离线壳缓存页面、题库与知识点；在线编译需要联网。
